## Purpose and scope of the manual

This practical manual outlines the functionalities of the ePiE (exposure to Pharmaceuticals in the Environment) model. The ePiE model predicts environmental concentrations (PECs) of active pharmaceutical ingredients (API) for human use in surface waters (i.e., rivers and lakes) across Europe based on per capita consumption data of APIs.  It is available as a web application ([https://shoeks.github.io/ePiE_webApp/](https://shoeks.github.io/ePiE_webApp/)), as a desktop application ([https://shoeks.github.io/ePiE_desktopApp/](https://shoeks.github.io/ePiE_desktopApp/)), as well as a standalone *R* package. This manual focuses on the usage of the web application, similar in its usage as the desktop application, and the *R* package. 
The  manual is separated into <mark>X</mark> sections:



1. Background information on APIs in the aquatic environment and exposure modelling
2. How to use the ePiE Web application
3. How to use the EPiE *R* package
4. Specific use examples
5. Model interpretation and limitations
